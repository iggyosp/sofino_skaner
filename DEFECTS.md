# Фиксация дефектов на складе

Мобильная страница в docs/ и сервер на Python в server/. Для запуска нужны репозиторий GitHub с Pages, сервер с постоянным HTTPS-адресом, пустая Google Таблица и рабочий аккаунт Яндекс Диска.

## Настройка

1. Создайте отдельную пустую Google Таблицу. В Google Cloud включите Google Sheets API, создайте сервисный аккаунт и выдайте его email право редактора именно этой таблицы. Сохраните JSON-ключ на сервере за пределами репозитория. ID таблицы находится в её URL между /d/ и /edit.
2. Для приложения Яндекс OAuth получите токен рабочего аккаунта Диска с правом записи в Диск. Отчёт содержит приватную ссылку на папку в веб-интерфейсе этого аккаунта. Проверьте открытие из учётной записи обработчика. Публичные ссылки приложение не создаёт.
3. При публикации Pages из main и /(root) форма дефектов открывается по пути /sofino_skaner/docs/. В docs/config.js задайте полный адрес HTTPS-сервера. Сотрудникам передайте ссылку на форму в /docs/.
4. На сервере установите переменные окружения из таблицы ниже. В каталоге server выполните команды:

   ```sh
   python3 -m venv .venv
   . .venv/bin/activate
   pip install -r requirements.txt
   python main.py
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

   Первая команда запуска main.py создаёт листы «Дефекты» и «Сводная». Используйте выделенную таблицу. Поместите сервис за HTTPS-прокси или разверните на платформе с HTTPS. Для контейнера собирайте server/Dockerfile из каталога server и выполните python main.py как разовую команду с теми же настройками и примонтированным ключом. Прокси должен принимать запросы до 7 МБ. Настройте перезапуск процесса.
5. На устройстве откройте ссылку Pages, введите ID и ключ устройства, разрешите заднюю камеру. ID и ключ запоминаются до закрытия вкладки. Для передачи телефона другому сотруднику нажмите «Сменить ID». ID указывает авторство со слов сотрудника. Ключ разрешает запись с устройства и выдаётся администратором.

| Переменная | Значение |
|---|---|
| PAGES_ORIGIN | Например https://company.github.io без пути и конечного слэша |
| SHEET_ID | ID таблицы |
| GOOGLE_APPLICATION_CREDENTIALS | Абсолютный путь к JSON сервисного аккаунта на сервере |
| YANDEX_TOKEN | OAuth-токен аккаунта Яндекс Диска |
| DEVICE_KEY | Длинный случайный ключ склада. Передайте сотрудникам отдельно от ссылки |
| DEFECT_TYPES | Необязательно. Утверждённые названия через вертикальную черту, например Повреждение упаковки&#124;Дефект товара. Пустое значение скрывает список |

## Карточка товара

Наведите камеру на один ШК. Приложение сохраняет распознанный кадр и переходит к общему виду. Если прочитать код невозможно, нажмите «Снять ШК и ввести цифры» и внесите цифры при проверке. Снимите общий вид и дефект, проверьте три снимка, укажите тип при необходимости и отправьте. Ведущие нули в ШК сохраняются. Для ручного ввода RID установлен текстовый формат. Склад и RID остаются свободными.

В Диске путь имеет вид /Дефекты/ШК_ID/ID-записи/. Вложенная папка отделяет повторные осмотры. Три JPEG имеют понятные имена. Сводная считает только случаи с указанным типом. Служебный ID записи защищает строку таблицы от дублирования при повторной отправке. Снимки хранятся в открытой вкладке до подтверждения. При обрыве связи оставьте вкладку открытой и повторите отправку. Прерванная загрузка может оставить папку на Диске без строки в таблице.

## Проверка на складе

Проверьте камеру и сканирование реальных этикеток на рабочих Android/iPhone. Сканер использует BarcodeDetector при наличии и ZXing с CDN как запасной декодер. Разрешите доступ к cdn.jsdelivr.net либо разместите UMD-сборку @zxing/library 0.21.3 в docs и замените ссылку в index.html. Проверьте ШК с ведущим нулём, повторную фиксацию того же ШК, пропуск типа и ручной RID. Откройте ссылку на фото из таблицы.

Измеряйте время от наведения на ШК до появления подтверждения на серии товаров в рабочей сети. Камера остаётся открытой между снимками, кадры сжимаются на телефоне до 1600 пикселей по длинной стороне, сервер загружает три JPEG параллельно. Цель — до 30 секунд на товар. Быстродействие облачных сервисов и сети требует замера на месте.
