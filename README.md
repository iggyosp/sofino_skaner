# Софьино — сканер маршрутов

Сканер для телефона, GitHub Pages и Google Таблиц. Запуск ещё требует развёртывания Apps Script и проверки с реальным телефоном.

## 1. Подключить таблицу (владелец)

1. Откройте вашу Google Таблицу с листом «Сканер». Выберите **Расширения → Apps Script**.
2. Скопируйте содержимое `Code.gs` из этого репозитория в файл кода редактора, заменив только пустую стандартную функцию. Если там уже есть действующий код — сначала сохраните его отдельно и проверьте конфликты имён.
3. В **Настройки проекта → Свойства скрипта** добавьте `SPREADSHEET_ID`: часть адреса вашей таблицы между `/d/` и `/edit`. Затем добавьте свойство `STAFF_KEY`. Значение — случайный пароль минимум из 20 символов (лучше сгенерировать в менеджере паролей). Не используйте пароль от Google. Не публикуйте значение в GitHub и не присылайте в чат.
4. Сохраните проект. В редакторе выберите функцию **setup** и нажмите **Выполнить**. Разрешите доступ к таблицам вашему собственному проекту. Она проверит заголовки A:D и добавит E — «ID записи». Существующие строки не удаляются.
5. Выберите **Развернуть → Новое развертывание → Веб-приложение**. Выполнять от имени: **Я**. Доступ: **Все / Anyone** (в том числе без входа в Google). Запросы записи дополнительно проверяются по STAFF_KEY. Таблица при этом НЕ становится публичной, её права менять не нужно. Если организация запрещает такой доступ, не обходите ограничение — потребуется другой сервер или корпоративная авторизация.
6. Разверните проект, скопируйте URL, заканчивающийся на `/exec`. Это адрес обработчика, а не ссылка на таблицу. `/dev` для сотрудников не подходит.
7. Откройте адрес в браузере: ожидается JSON с `ok: true`, `service: sofino-scanner`. Это проверка доступности, а не успешной записи.

Официальная инструкция: https://developers.google.com/apps-script/guides/web .
После изменения Code.gs: Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть.

## 2. Включить GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save. Включите HTTPS.
Ожидаемый адрес после успешной публикации: https://iggyosp.github.io/sofino_skaner/ .
Это ожидаемый адрес, факт публикации нужно проверить в Pages. `Code.gs` не исполняется на GitHub — он предназначен для редактора Apps Script. В репозитории нет ключей или паролей.

## 3. Проверить и выдать сотрудникам

1. Откройте сайт в Chrome/Safari на рабочем телефоне, не во встроенном браузере мессенджера.
2. Введите сотрудника и маршрут. В настройках укажите адрес `/exec` и ключ сотрудников.
3. Введите вручную тестовый код, например `TEST-001`. Дождитесь сообщения о подтверждении Google Таблицей. Проверьте появление строки на листе «Сканер», включая ID в столбце E. Затем можно вручную удалить эту тестовую строку в таблице.
4. Проверьте настоящий штрихкод камерой и соответствие ожидаемому ID. Исходный нестандартный декодер Мартинкевича теперь включается отдельно. По умолчанию сохраняется исходное содержимое кода.
5. На уже открытой странице отключите сеть, добавьте тестовый код. Он должен остаться «Ожидает». Включите сеть: запись должна появиться ровно один раз. Перезагрузите страницу и снова введите ключ, чтобы проверить восстановление очереди.
6. После этих проверок раздайте ссылку на сайт, адрес обработчика и ключ сотрудникам по вашему внутреннему каналу.

## Поведение и ограничения

- Дата и время сканирования берутся с телефона, отображаются в таблице в часовом поясе Москвы. Часы телефонов должны быть корректными.
- Автоотправка: при сканировании, восстановлении сети и каждые 30 секунд, пока страница открыта. Фоновая отправка после закрытия страницы не гарантируется. После перезагрузки ключ вводится заново.
- Код хранится как текст, ведущие нули сохраняются. Поля не исполняются как HTML или формулы.
- На телефоне повтор кода в том же маршруте блокируется до очистки отправленных. Проверка товарных дублей между сотрудниками НЕ реализована. ID записи в E защищает только от повторной сетевой отправки одного события. Столбец E нельзя очищать отдельно от строки.
- Очистка на телефоне затрагивает только подтверждённые записи. Новые/неотправленные сохраняются. Таблица не очищается.
- Резервная копия JSON включает текущие записи и прежнее хранилище scanner_routes, если оно существовало на том же адресе. Старые записи автоматически не отправляются: в них нет даты и сотрудника. Автоматическое восстановление из JSON пока не реализовано.
- Работайте в одной вкладке на устройстве. При изменении хранилища другой вкладкой текущая блокируется во избежание перезаписи очереди.
- Сайт публичный. Общий ключ защищает запись, но не является индивидуальной авторизацией: сотрудник с ключом может указать любое имя. Обработчик не выдаёт содержимое таблицы. Для персональных прав и аудита нужна полноценная авторизация.
- Это пилот для небольшой команды. Apps Script имеет квоты; поиск ID читает весь заполненный столбец E. При большом числе записей нужна база данных и другой сервер.
- Внешняя библиотека html5-qrcode закреплена на 2.3.8. Для первой загрузки страницы и библиотеки нужен интернет; полноценный офлайн-запуск не реализован.
- Ответ Google читается через fetch с text/plain и перенаправлениями. Нельзя заменять на no-cors: непрозрачный ответ не доказывает запись. Если браузер/политика Google блокирует ответ, очередь сохраняется; нужно устранить причину, а не помечать записи отправленными.

## Локальная проверка

`node tests.cjs` — проверка серверного обработчика с имитацией сервисов Google: неправильный ключ, повтор одного события, блокировка, валидация пакета и текстовые поля. Это не заменяет проверку настоящего развёртывания и камеры.
